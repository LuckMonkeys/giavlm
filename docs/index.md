# GIAVLM 实验笔记

本项目研究联邦微调视觉语言模型（VLM）时的隐私泄露，第一条验证路径是 SLAKE + LLaVA-1.5-7B。

- 当前阶段：方法和协议诊断。
- 目前还没有可用于论文的基准结果。

## 核心结论

每条结论都给出最有力的证据。当某个 key 实验的结论发生变化时，需要同步更新这里。

- **IG 无法从 LLaVA 的更新中重建图像**：所有测试设置都停留在噪声水平；即使从紧挨真实图像的位置出发，也会漂移到约 19–20 dB，同时匹配损失还在下降。
    - 证据：[[ig-failure-diagnosis]]、[[ig-strategies-and-rounds]]
    - 证据强度：使用私有数据的诊断，3 张图像，所有设置的结果一致
- **损失能分辨图像的远近，但梯度不指向真实图像**：训练后近候选比远候选损失更低的概率（near-win）达到 0.96–0.98，但局部像素梯度几乎与指向真实图像的方向正交，这正是 IG 失败的原因。
    - 证据：[[gradient-discriminability]]
    - 证据强度：在 20 张独立图像上验证（使用私有数据的诊断）
- **仅靠模板或随机词猜文本时，图像信号基本消失**：训练后的 F-L、F-CL 失去了图像排序能力（rho 约为 0 和 −0.12）；知道正确答案时还能保留一部分。
    - 证据：[[text-unknown-discriminability]]
    - 证据强度：开发集，20 张图像，尚未独立验证
- **找齐 token 仍不足以恢复图像排序**：全部正确 token 保留但问题和答案都乱序时，rank 8、32 的 rho 为 −0.037、0.046；只乱序问题而保留正确答案时仍有正向排序。
    - 证据：[[text-unknown-discriminability]] 中 2026-10-11 的配对诊断
    - 证据强度：使用私有数据的开发集诊断，十张图像、六种问答、两个排列种子
- **无先验的 Residual 重构只保留部分图像信号**：rank 8 的 rho 为 −0.409，rank 32 为 0.305；rank 32 仍低于正确文本的 0.733，尚未验证图像优化能否利用这一信号。
    - 证据：[[text-unknown-discriminability]]
    - 证据强度：同一组十张图像的配对诊断，模型状态与文本同时随 rank 变化
- **语言先验改善文本后，图像排序也随之改善**：固定权重 0.01 后，开发集 rank 8、32 的 rho 分别升至 0.355、0.690；rank 32 新问答验证从 0.256 升至 0.578，但两个文本错误样本都出现排序反转。
    - 证据：[[text-unknown-discriminability]] 中 2026-10-12 的配对诊断，重构来源为 [[dager-lm-prior]]
    - 证据强度：每个队列十张图像；rank 32 验证集配对增益区间跨 0，仍属小样本诊断，不代表图像或属性恢复成功
- **非显式文本下出现模态预测增益，但独立视觉结论仍未确定**：三类各十张的新队列中，重构文本下主公开库的梯度准确率为 18/30，Model-only 为 12/30，校准 Text-only 为 16/30；完整问答恢复为 17/30。
    - 证据：[[image-property-inference]]，包含首轮 pilot、三库稳定性、同部位子集和配对检验
    - 证据强度：新队列与首轮目标隔离；主方法相对文本对照的增益区间跨 0，腹部主结果不稳定，探索性中心化等权为 7/8，需在新图像上冻结验证
- **合成候选能在混合模态小样本中支持头部属性推断**：二十图的实际重构文本下，预定主方法为 18/20，Model-only 为 14/20，正确文本诊断为 19/20；CT、MRI 组内分别为 7/8。
    - 证据：[[synthetic-head-property]]，从 [[synthetic-ct-property]] 的 CT 示例扩展到原始问答与混合模态
    - 证据强度：小规模诊断，十三图与此前 pilot 重叠；新增七图正确六张但模态与属性相关；相对 Model-only 的增益区间为 [0.00, 0.40]，尚未独立验证
- **即使图像私有，文本的 token 集合也会泄露**：residual 打分把 96–98% 的私有 token 排进 32k 词表的前 100 位，用真实图像或 random surrogate 都是如此。
    - 证据：[[dager-multisample-n10]]，以及 [[dager-filter-phase]] 中的基线结果
    - 证据强度：开发集 n=10，另有 40 张验证图像支持筛选器的结果
- **提高 rank 后，已知图像时可以恢复部分完整问答**：搜索实现和预算不变，Residual 的 Joint EM 从 rank 8 的 0/10，升到 rank 16 的 1/10 和 rank 32 的 5/10；rank 16 和 32 均恢复全部问题。
    - 证据：[[dager-lora-rank]]、[[dager-multisample-n10]]
    - 证据强度：同一开发集十张图像的配对比较，覆盖六种问答，尚未独立验证
- **原 Residual 在随机图像下仍难恢复完整序列**：rank 32 的候选全覆盖为 9/10，答案恢复 3/10，但完整问题和问答仍为 0/10；问题 ROUGE-L 从 rank 8 的 0.454 升到 0.898。
    - 证据：[[dager-lora-rank]]
    - 证据强度：同一开发集十张图像的配对比较
- **纯文本先验改善未知图像下的序列恢复**：rank 32 冻结权重 0.01 后，新问答验证的 Question EM、Answer EM 均为 9/10，Joint EM 从原基线的 0/10 升到 8/10；默认先验仍关闭，实现已提交。
    - 证据：[[dager-lm-prior]]
    - 证据强度：开发集选择权重后，在十个新图像组、十种不同问答上冻结验证；其中八种问题文本未在开发集出现
- **相同先验权重在 rank 8 只有有限收益**：原十样本的 Joint EM 从 0/10 升到 2/10，成功对应同一种问答；四个样本候选不完整，另有四个候选完整的样本仍在问题阶段被剪枝。
    - 证据：[[dager-lm-prior]]
    - 证据强度：用户固定权重的原开发集配对扩展，覆盖六种问答，未追加独立验证
- **改进 token 筛选没有稳定的效果**：三种改进在开发集上都有提升，但在新图像上要么失效，要么退化，因此保留现有筛选器。
    - 证据：[[dager-filter-phase]]
    - 证据强度：冻结后的独立验证

**下一步**：属性推断优先扩大同部位的独立样本，冻结验证中心化等权评分，并保留文本与模型对照；文本重构继续区分 rank 8 的早期剪枝和 rank 32 的最终排序失败（见 [Handoff](PROJECT_HANDOFF.md)）。
