# 图像属性下一阶段计划

日期：2026-10-28。状态：待实施；本文件只规划后续实验，不表示已经实现或启动任务。

前序设计见[图像属性推断方案](2026-10-28-image-property-ideas.md)，已完成结果统一见[图像属性方法验证](../experiments/2026-10-28-image-property-ideas.md)。旧计划保留已执行阶段的设置，本文件作为下一阶段唯一计划入口；后续执行细案直接补充到本文件，结果继续归入同一实验记录。

## 目标与优先顺序

目标是检验：**在不提供目标图像领域标签的条件下，能否从客户端更新中提取超出恢复文本与模型先验的图像属性信息？** 第一阶段仍只预测预定义属性，不扩展到像素恢复或自由描述。

| Route | Research question | Priority | 本轮定位 |
|---|---|---|---|
| A 跨风格统计 | 多风格中稳定的候选梯度方向能否迁移到未见领域？ | 主验证路线 | 改进现有评分，最容易与旧结果比较 |
| B 表征与梯度探针 | 可读出的属性方向是否也能在可观察梯度中识别？ | 小规模探索 | 深层读出、同模态原型分别验证，不能直接等同 |
| C 文本引导生成 | 恢复问答能否自动提供有效场景条件？ | 条件性补充 | 消除人工指定领域，不声称消除视觉先验 |
| D 受约束 tokens 恢复 | 低梯度误差能否约束出属性正确且稳定的视觉表征？ | 先检查二阶链，再小规模验证 | 延续旧 E2，研究候选排序以外的信息利用 |

执行顺序：先完成公共协议与 D0 工程检查；准备多风格公开库后优先 A；D0 通过则推进 D1。B 只分配小规模前提检查，C 在完成文本场景分组后再执行。不要同时搜索全部路线、全部参数和全部目标。

本页 A–D 是下一阶段编号；D0–D2 对应旧计划的 E2/E3 延伸，并非旧计划的梯度概念探针 D2。

## 如何整合两份分析

### 已有证据与待证假设

| Observation | 已支持的解释 | 尚不能推出的解释 |
|---|---|---|
| 摄影库留出接近满分，医学目标约 0.533–0.583 | 当前公开选择不能预测目标域表现 | 判别方向一定是肤色、头发，或与医学方向几乎正交 |
| 所选加权为 beta=0，其他 beta 也未改变分类 | 当前有界权重没有分类收益 | 所有层筛选或加权都不可能有效 |
| 投影后类内变化与类间分离都下降 | 估计的干扰空间可能与判别信息重叠 | 删除类内方向就得到了纯语义 |
| 首层概念探针失败，真实 tokens 读出成功 | 当前静态词向量几何不足，完整网络仍能识别属性 | 已证明具体的视觉锥结构，或深层完全消除了模态差异 |
| 医学库比通用库效果好 | 候选分布值得控制和适配 | 文本引导生成必然从 0.55 恢复到 0.90 |

单域数据不足以识别一般的跨域不变性，但不是“单域永远不可能泛化”。模型预训练可能已经提供可迁移特征。新增实验应测量方向一致性及域外预测，而不是将其当作前提。

Modality gap 是合理解释之一；[Mind the Gap](https://arxiv.org/abs/2203.02053)研究了 CLIP 等多模态对比表征的几何差异，不能替代当前 LLaVA 层级表征的实测。原始探针还受词簇、词片段平均、秩截断、归一化和判别阈值影响。

Logit lens 是对隐状态的词表读出，不是对任意参数梯度的读出。[Tuned Lens](https://arxiv.org/abs/2303.08112)也指出原始 logit lens 可能不稳定。因此，深层路线首先检查空间与位置对应关系，不直接把末层 LoRA 梯度与输出词向量相比较后解释为语义恢复。

### 图像先验的三种边界

| Condition | Meaning | Applicable route |
|---|---|---|
| Domain-label unknown | 攻击输入中没有真实领域标签；允许从恢复文本估计 | A、B、C、D |
| Target-domain absent | 公开拟合库、开发集和视觉字典不含最终测试领域 | A、B 的视觉原型、D |
| No auxiliary images | 无公开图像、生成图像或视觉字典 | 仅未引入视觉辅助数据的 B 探针变体 |

C 使用生成模型先验；D 使用视觉字典时仍有图像先验。它们不能命名为 Zero-prior 或 Image-free。低维线性空间、凸包也不等于真实图像的非线性流形。

## A 跨风格统计与域差分抑制

### 假设与方法

检验不同公开风格中可重复的类别方向，是否比单域类内散度更能预测库外判别力。固定同一问答 $\hat t$，令第 $\tau$ 个梯度张量展平后的类中心为 $\mu_{\tau,d,c}$，定义

```math
\Delta_{\tau,d}=\mu_{\tau,d,1}-\mu_{\tau,d,0},\qquad
s_\tau=\frac{1}{|\mathcal P|}\sum_{(d,e)\in\mathcal P}
\max\{0,\cos(\Delta_{\tau,d},\Delta_{\tau,e})\}.
```

$\mathcal P$ 仅包含拟合风格对。类别方向范数过小时标记无效，不把数值噪声归一化成强证据。权重使用

```math
w_\tau=\frac{1-\beta}{T}+\beta\frac{s_\tau}{\sum_\nu s_\nu},
\qquad \beta\in\{0,0.5,1\}.
```

只在有效张量上归一化；全部一致性无效或为零时回退等权并记录。第一轮保持 Centered equal-tensor Top-3 的中心与聚合规则，仅改变权重。若只用一个拟合风格，跨风格权重不可定义，使用旧有界散度权重对照。

显式域差分使用每类跨风格中心变化：

```math
E_{\tau,\mathrm{domain}}
=\left[\mu_{\tau,d,c}-\bar\mu_{\tau,c}\right]_{d,c},\qquad
P_\tau=I-\alpha U_{\tau,k}U_{\tau,k}^{\top}.
```

$\bar\mu_{\tau,c}$ 是各拟合风格的等权类中心；$U_{\tau,k}$ 来自该矩阵的 SVD。二类、两种拟合风格时独立方向至多两个；取 $k=1$ 或全部有效秩，不能照搬旧类内 SVD 的 k=4。$\alpha\in\{0,0.5,1\}$，目标与候选使用同一中心、同一变换。

跨风格一致性高也可能来自各风格共享的背景或构图捷径。因此每类应匹配背景、主体占比、生成预算及负例组成；对域差分投影同时测量类间分离保留，不能只看域分类困难了多少。

### 最小实验

| ID | Comparison | Main question |
|---|---|---|
| A0 | 等预算单风格库与多风格库，均用原等权评分 | 多样性本身是否足够带来收益？ |
| A1 | 多风格等权、旧散度加权、跨风格一致性加权 | 一致性统计是否提供额外收益？ |
| A2 | 同一多风格原型评分下，不抑制、类内抑制、域差分软抑制与硬投影 | 显式域差分是否优于混合类内变化？ |
| A3 | 标签置换、权重置换、同问答相反属性的梯度交换 | 收益是否依赖正确的类结构和目标上传？ |

先分别评估加权和投影，均有证据后才允许一个组合配置。记录各层、模块与 LoRA 因子的方向一致性、有效张量比例、权重集中度和域外误差；不预设深层更好。

推进条件：公开三折中至少两折相对等预算等权基线改善，平均 Balanced accuracy 至少提高五个百分点，且 AUROC 不下降，才冻结一个主配置进入新目标确认。这是资源分配门槛，不是显著性或理论保证。若收益只来自候选数量或多样性，则保留数据构造结论，不宣称加权有效。

## B 表征探针与梯度探针分开验证

### B0 深层读出是否更稳定

先在公开开发图像上保存两个位置的隐状态：视觉 token 位置，以及固定属性问句末端、首个答案生成前的位置。答案尚未提供，避免 teacher forcing 直接带入正确标签。因果掩码下，较早的视觉位置不能读取后面的属性问句；不能把二者混成一种表征。

对深度 $\ell\in\{1,8,16,24,32\}$ 的 block 输出测试

```math
\operatorname{logits}_{\ell}=W_{\mathrm{out}}\,operatorname{Norm}_{\mathrm{final}}(h_{\ell}).
```

层数与具体 hook 名从模型读取；上式只针对当前三十二层模型。固定 yes/no 首 token 的 logit 差作为逐层诊断，输出位置保持一致；末层还复现旧 E1 的完整答案 NLL。概念词若为多 token，不能未经声明把输出词向量均值当作完整词概率。

该实验只定位读出能力，不是攻击。若训练公开对齐层或 tuned lens，另记辅助训练数据、拟合量与复杂度，不混入未训练探针。

### B1 从深层隐状态到梯度的边界

对某个 LoRA 线性模块，采用行 token 矩阵 $X\in\mathbb R^{n\times d_{in}}$、反向误差 $\Delta\in\mathbb R^{n\times d_{out}}$，有

```math
G_A=sB^\top\Delta^\top X,\qquad
G_B=s\Delta^\top XA^\top.
```

该关系由 [LoRA 的低秩参数化](https://arxiv.org/abs/2106.09685)直接求导得到。它意味着：

- $G_A$ 的行空间受该模块输入空间限制，不是完整深层隐状态。Q/K/V、attention output、MLP 的输入坐标不同；维度相同也不足以直接套用 LM Head。
- $G_B$ 的列空间是被低秩输入压缩后的反向误差方向，不是完整上游误差，更不是前向语义表征。
- 深层文本激活已依赖图像，不能只用恢复文本精确重建并投影消掉。最终 RMSNorm 与中间模块归一化也不能省略。

因此不直接将 $W_{out}[w]$ 到任意深层梯度行空间的距离设为主攻击。只有明确对应模块和坐标、公开激活诊断通过后，才测试该距离作为启发式，并与公开原型及无关输出词对照。

### B2 同模态视觉原型

从公开拟合图像的实际模块输入提取两个类别原型 $p_0,p_1$，先用相同位置平均与归一化规则检查它们对留出图像的分类能力，再测试到观测梯度行空间的相对距离。分别报告表征可分性与梯度压缩后的可分性。

**不能只使用一个差向量解决二分类。** 若两个探针只是 $\delta$ 与 $-\delta$，它们到任意线性子空间的距离相同；中心化的二类均值也可能互为相反数。梯度行空间本身没有这个符号信息。若二类原型距离退化，停止该距离路线；只有恢复了带方向的特征或拟合了另一个公开判别器，才能使用有符号判别。

| ID | Test | Stop condition |
|---|---|---|
| B0 | 固定层、固定位置的公开前向读出 | 不把读出成功当作梯度证据 |
| B2a | 公开视觉原型跨风格分类 | 留出域原型不分离，则暂停对应梯度探针 |
| B2b | 同一公开查询的模块输入空间与梯度行空间比较 | 距离退化、方向不稳或梯度版本无收益则停止 |
| B2c | 同问答交换图像梯度、零视觉输入、无关原型 | 不能优于先验与错配上传，则不扩大规模 |

旧主探针先保持冻结。rank=32 与 synonyms 的探索性好结果可以在新公开开发集确认，但不得用它替换旧主结果。没有证据时，不把“深层”本身作为方法贡献。

## C 恢复文本引导候选生成

### 核心设计

固定生成器与场景提取器，由恢复问答产生场景描述 $s=f(\hat q,\hat a)$；每个候选类别都使用同一个 $s$，只改变预先定义的属性条件。保留生成提示、随机种子与标签核验日志。

在评分前由评估端固定三个文本分组：场景明确、场景模糊、没有场景线索；另标记属性是否已被文本直接揭示。分组仅用于分析，不能向攻击者返回真实场景。攻击者的场景未知处理规则必须预先固定。

| Condition | Candidate context | Purpose |
|---|---|---|
| Generic | 固定通用上下文 | 原基线 |
| Fixed mixture | 与文本无关的固定多风格混合 | 区分适配收益与多样性收益 |
| Recovered context | 恢复文本自动生成的上下文 | 主条件 |
| Shuffled context | 预定其他样本的恢复上下文 | 上下文有效性对照 |
| Correct context | 评估端真实领域 | 私有参考诊断，独立运行且不能选参 |

各条件固定每类十二个候选及相同生成尝试预算，沿用冻结 Top-3 评分。标签核验失败时记录失败率；有限补齐次数执行前固定，仍不足则记覆盖失败，不能无限生成到正确。不能按目标匹配分数筛选生成提示。

相同候选库同时计算完整梯度评分、既有 Model-only、Text-only 和错配梯度结果；Model-only 的具体实现及输入沿用旧基线并记录，不能偷偷给它目标真图。若生成器必须访问外部服务，默认先用本地模型；包含恢复私有问答的外发须另行获得用户授权。

推进条件：恢复上下文比等预算固定混合更好，且在文本未直接揭示属性的组中仍有超出先验对照的梯度增益。只在场景明确组有效时，报告条件性适配；不得承诺恢复到旧医学库的 90%。

## D 受约束视觉 tokens 恢复

### D0 二阶链检查

复用 `evaluation/visual_concept_probe.py` 的视觉注入接口和原生训练损失，模型参数固定，只优化视觉变量。旧 E1 检查的是训练损失对视觉变量的一阶梯度，尚未证明下式可计算：

```math
\nabla_Z D\!\left(\nabla_\theta\mathcal L_\theta(Z,\hat t),g^\star\right).
```

实现需用 `create_graph=True` 保留内部参数梯度图；检查 attention kernel、checkpoint 和 autocast 是否支持双反向，模型与 loss mask 必须与上传一致。候选视觉变量使用 FP32 master copy，不能因 bf16 舍入使小更新无效。

先用四个类别平衡的公开样本检查：注入一致性、二阶梯度有限且非零、一次实际更新是否改变匹配目标，以及可控 FP32 小模型上的方向有限差分。真实 bf16 模型的差分存在量化误差，不强行套精确差分门槛。

若执行后端不支持双反向，显式记录并验证替换后端的前向与一阶梯度一致性；不能静默改变条件或不断重试 OOM。D0 不通过就暂停优化路线。

### D1 首轮使用凸组合，PCA 作为后续消融

公开字典由同一模型、同一预处理得到 $Z_i\in\mathbb R^{576\times4096}$；实际形状从适配器读取。首轮优化

```math
Z(\alpha)=\sum_{i=1}^{M}\alpha_i Z_i,
\qquad \alpha_i\geq0,\quad \sum_i\alpha_i=1.
```

可以用 softmax 参数化权重。拟合字典采用两种非目标风格、两类平衡的三十二张公开图；不能按目标真值选类别、按目标真图选近邻或用公开查询自身初始化。无优化字典平均与三个固定随机权重种子都要保存属性读出。

凸组合与“选择字典中最匹配的一张图”分别比较。图像之间 patch 位置未必对应，混合后的 tokens 不一定属于合法图像；凸约束只能限制搜索空间，不能保证语义合理。

若凸组合可优化但受字典表达能力限制，再测试整幅 token 矩阵向量化后的 PCA：

```math
\operatorname{vec}(Z)=\mu+U_k\Lambda_k^{1/2}a,
\qquad k\in\{8,16\},\quad \|a\|_2\leq R.
```

$R$ 根据公开拟合样本系数范数的预定分位数设定并冻结。这里是整幅 tokens 的低维子空间，不能与“每个 patch 独立拥有低维系数”的高维优化混淆。完整字典只有 M 张时，PCA 有效秩至多 M−1。

### 目标函数与输出选择

主损失使用固定上传块集合的归一化平方误差，分母下限由观测梯度块能量的预定相对规则确定：

```math
L_{\mathrm{match}}(Z)=\frac1{|\mathcal T_{fit}|}
\sum_{\tau\in\mathcal T_{fit}}
\frac{\|g_\tau(Z,\hat t)-g^\star_\tau\|_F^2}
{\|g^\star_\tau\|_F^2+\epsilon_\tau}.
```

同时记录余弦和范数误差，但首轮不切换多个损失挑最佳。属性 yes/no 读出只在候选 tokens 保存后执行，**不进入优化目标、早停或初始化选择**。

按层与模块分层保留约 20% 上传块作匹配验证，分块规则只由公开参数名确定。拟合其余块，按保留块匹配损失选择 checkpoint 和初始化；该验证仍使用同一次上传，只用于检测拟合块过拟合，不能代替独立目标验证。选定后报告全部块误差。

| ID | Comparison | Purpose |
|---|---|---|
| D1a | 不优化的字典平均、随机凸组合、最佳单候选 | 测量公开视觉先验及已有搜索能力 |
| D1b | 同一字典与预算下优化凸组合 | 检验连续优化能否超出候选选择 |
| D1c | PCA 约束与凸组合 | 仅在 D1b 完成后定位字典表达限制 |
| D2 | 多初始化、错配梯度、无目标梯度、四个公开查询的自由 tokens 对照 | 检查先验偏置、多解和约束作用 |

无目标梯度对照直接使用相同初始化或公开先验目标，不将全零向量冒充有效上传。自由 tokens 只作小规模诊断，若要证明约束有益，必须让自由与受约束条件使用相同查询和近似计算预算。

### 最小运行预算与推进条件

首轮十二个独立公开查询，每个三次初始化，每次最多一百步，仅测试凸组合主优化；另保存未优化与单候选基线。优化器、学习率和数值下限先在四个工程样本上确认，然后在 pilot 前冻结，不能看 pilot 属性准确率后调整。记录每步参数梯度回放、耗时与显存；最多 3600 个优化步不等于固定小时数。

判断分为三层：

- **可计算**：D0 通过，匹配损失与保留块误差可稳定下降。
- **可读出**：仅按匹配分数选出的解，相对同字典未优化及最佳单候选有属性收益，而不是只降低损失。
- **可辨识**：预先定义近最优匹配阈值（例如保留块损失在最优的 5% 内并加数值容差），统计这些解的属性冲突率；不能只挑一个属性正确的解展示。

小规模收益仅用于决定是否扩大；正式推进仍需新目标配对区间及先验对照。若匹配良好的多个解给出相反属性，应将其记为该条件下的经验歧义，考虑拒答，而不是保证更强正则能恢复真值。不能据少量失败证明属性在理论上不可辨识。

## 共用评价与推进门槛

| Dimension | Required report |
|---|---|
| Classification | Balanced accuracy、Macro F1、每类 Recall、Head AUROC；固定阈值仅由公开开发集确定 |
| Incremental evidence | 相对原等权评分、同字典候选选择及适用先验基线的配对差异 |
| Gradient specificity | 同问答、相反属性、同模态受控样本的梯度交换；自然问答错配另报 |
| Domain | 每个领域单独结果、最差领域表现、域外平均；风格变化与成像变化分开 |
| Text | 恢复文本主结果；正确文本诊断；属性直接揭示与未揭示分别报告 |
| Reliability | 近最优解冲突、跨种子稳定性、拒答率与覆盖率；不能只报接受样本准确率 |
| Uncertainty | 按独立目标配对 bootstrap；同患者、同源图或同提示家族跨库一起成组 |
| Cost | 生成尝试数、有效候选数、梯度回放数、二阶优化步数、时间与显存 |

公开开发阶段最多冻结一个主方法进入独立测试；其他路线明确为探索性。确认收益要求相对主基线的目标级配对 95% 区间下限大于零，并同时报告先验增量。没有达到门槛时如实报告不确定，不根据测试结果重新选择词簇、领域或样本。

目标属性若已由恢复文本直接给出，属于文本泄漏延伸；要支持图像属性泄漏贡献，需要在未直接揭示组中仍观察到目标梯度增益。辅助模型判断只作标注帮助，不能代替独立真值。

## 实现与产物安排

### 可以复用什么

| Existing component | Reuse | Limitation |
|---|---|---|
| `evaluation/property_geometry.py` | Gram 统计、等权、投影、Fisher 对照 | 跨风格中心差与一致性权重需新增 |

| `evaluation/visual_concept_report.py` | 分类指标和预测后评估 | 新家族区间需跨库合并同一提示，不能沿用旧分组方式 |

实现时将仅依赖 Observation 与公开辅助数据的拟合、评分、优化同真值评估分开。若进入正式 benchmark，再按项目接口返回 `Reconstruction`；本计划不默认已有攻击方法注册。

### 执行清单

1. 冻结公开数据与目标划分、属性规则、主对照、模型指纹、输入知识和候选预算；核对 Observation 没有携带额外私有字段。
2. 完成 A 的等预算统计单测与 D0 的二阶工程检查；B 的 hook 必须记录模块、位置、归一化和维度。
3. 分阶段运行开发 pilot，产物只使用 JSON 与 safetensors；保存配置、源码哈希、选择规则与全部连续分数。
4. 在读取查询真值前写入 `predictions_complete.json`；评估脚本单独生成报告，不覆盖历史产物。
5. 确认单一主方法与公开开发选择依据，再一次性评估独立目标；失败、停止和无收益阶段也记录。

本轮不指定 GPU 或承诺半天完成。后续执行前读取服务器规则、检查空闲资源，按项目上限使用 GPU，冻结运行源码并验证首个产物；OOM 或后端异常按既定规则停止并记录。

所有结果继续补充到[统一实验记录](../experiments/2026-10-28-image-property-ideas.md)，已完成与待执行严格分开。当前文件不新增实验结果、不改变旧数值，也不启动 GPU、生成模型或外部 API 任务。

## 预期结论如何表述

- A 成功：多风格统计在所测未见领域改善属性推断；不表述为提取了纯语义或完全消除了领域差异。
- B 成功：特定层、位置与模块存在可验证的属性读出或梯度判别关系；前向读出与梯度攻击分别成立后才连接起来。
- C 成功：恢复文本减少了人工指定领域的需求；说明上下文缺失或恢复错误时的适用边界。
- D 成功：梯度约束可得到支持正确属性读出的视觉表征；除非另有图像证据，不称为恢复真实视觉 tokens 或真实图像。
- 各路线仍失败：保留关于域迁移、表征几何和梯度歧义的实证边界；不将负结果扩大为模型不存在属性泄漏。
