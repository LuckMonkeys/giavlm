## 当前证据与方案排序

现有方法用同一份问答回放各候选图像的梯度，比较候选梯度与观测梯度，再按属性聚合。它测量的是梯度相似度，尚未把属性、成像方式、背景与文本交互分开。主评分是 Centered cosine，每类取损失最低的三个候选求均值。实现位于 `evaluation/image_property_scoring.py`。

同一批二十张目标上，医学候选库在恢复文本下达到 18/20；三套通用摄影库平均为 0.550，使用正确文本时平均为 0.517。这说明当前方法依赖候选分布，不能据此断言梯度中没有跨域属性信息。库替换同时改变了结构、颜色、背景与构图，也不能把全部差异归因于单一风格因素。[实验记录](../experiments/2026-10-16-synthetic-property.md)

| Idea | Priority | 可行性判断 | 主要待证假设 |
|---|---|---|---|
| 方案二 Tensor Discriminability Weighting | 优先验证 | 最接近现有实现，便于定位问题 | 库内判别力能够预测库外判别力 |
| 方案一 Within-Class Variation Suppression | 随后验证 | 有统计依据，建议比较软抑制与硬投影 | 类内变化存在可迁移方向，且不会抹除属性差异 |
| 方案三乙 Visual Subspace Concept Probing | 先做小规模几何检查 | 成本较低，但原始理论链条不成立 | 概念词与视觉残差空间具有可用的几何对应 |
| 补充方案 Visual Token Recovery | 分阶段探索 | 绕开候选库更直接，但优化与可辨识性更难 | 梯度一致的视觉表征仍保留正确属性 |
| 方案三甲 Text-Guided Candidate Generation | 条件性补充 | 工程可行，依赖文本场景线索 | 恢复问答足以约束候选领域 |

上述排序表示验证顺序，不表示预期准确率。可以统一研究“抑制干扰、保留属性证据”，但暂不以“完美理论对称”作为方案成立的依据。

## 共同定义与实验边界

设目标上传为 $g^\star$，恢复问答为 $\hat t=(\hat q,\hat a)$，属性类别为 $c\in\mathcal C$。对于公开候选图像 $I_i$，计算

```math
g_i=g_\theta(I_i,\hat t)
=\nabla_\theta\mathcal L_\theta(I_i,\hat q,\hat a).
```

这里 $\theta$ 只包含实际上传的可训练参数。所有候选使用相同模型、问答、模板和训练损失。属性提示词用于候选设计或属性读出，不能替代原训练问答后仍声称在匹配同一个更新。

- 首轮固定单样本、单步 FedSGD、无防御，先分离图像侧问题。多步 FedAvg、AdamW 和受保护上传需要分别建模，不能直接套用原始梯度等式。
- 主要攻击条件使用已保存的恢复文本；正确文本仅通过显式 `text_known` Observation 提供，作为独立诊断条件。禁止根据目标真值选择使用哪一种文本。
- 属性类别、候选标签、词簇和生成提示在目标评分前确定。真图、真标签与私有特征仅由评估端在预测保存后读取。
- 方案一和二允许用公开候选标签拟合统计量，不能用目标标签调秩、权重或阈值。候选梯度依赖 $\hat t$，因此通常需要为每份不同的恢复问答重新计算。
- “减少目标域先验”分开报告：不提供目标域标签、候选库不含目标域、无需候选图像。这是三种不同条件。
- 模态、领域与风格分别记录。灰度化普通照片不是 CT，也不能用“多种风格”代替“覆盖不同成像机制”。

## 方案一 类内变化抑制

建议工作名称为 **Within-Class Variation Suppression**。在验证类内变化的来源之前，使用“类内变化”比直接命名为“外观噪声”更准确。

### 思路与数学形式

设候选数为 $N$，类别数为 $C$，每类数量为 $n_c$。把梯度展平为列向量，定义

```math
\mu_c=\frac1{n_c}\sum_{i:c_i=c}g_i,
\qquad
\bar g=\frac1N\sum_i g_i,
\qquad
E=[g_1-\mu_{c_1},\ldots,g_N-\mu_{c_N}].
```

令 $U_k\in\mathbb R^{p\times k}$ 为 $E$ 的前 $k$ 个左奇异向量，则

```math
P_k=I-U_kU_k^\top,\qquad
s_c=\cos\!\left(P_k(g^\star-\bar g),P_k(\mu_c-\bar g)\right).
```

本文件采用列向量约定；若把正交基存为行向量，对应形式为 $I-U_k^\top U_k$。目标与原型必须使用同一中心和同一变换。投影后范数过小，应记录无有效证据，不能把零向量当作匹配成功。

更稳妥的首轮对照是软抑制：

```math
P_{k,\alpha}=I-\alpha U_kU_k^\top,\quad 0\leq\alpha\leq1.
```

$\alpha=0$ 不抑制，$\alpha=1$ 为硬投影；中间值只是收缩算子，不是正交投影。它允许在降低类内变化的同时保留重叠的属性信息。

### 理论上成立需要什么

一个足以解释此方法的简化假设是

```math
g(I,\hat t)=b(\hat t)+s_c+U_n a_I+\epsilon_I.
```

如果公开库学到的子空间覆盖目标的干扰变化，并且投影后的 $s_c-s_{c'}$ 仍非零，属性可能继续可分。实际梯度还可能存在属性、领域和文本的交互，这个加性分解需要验证。

- **类内变化不全是风格。** “头部”内部还有不同解剖结构和视角；“非头部”内部甚至包含多个器官与对象。这些变化可能与目标属性的表达共享方向。
- **硬投影可能删除有用信号。** 属性差异与类内主方向不必正交。必须同时测量类内变化下降和类间分离保留。
- **训练库内压缩容易出现。** $\operatorname{rank}(E)\leq N-C$。删除全部类内方向会使该库内的类内方差接近零，这本身没有证明跨域语义恢复。
- **覆盖多种公开风格不保证覆盖未知领域。** 只有目标干扰落入所学子空间时，消除才有效；照片和线稿之间的差异未必覆盖 CT 与 MRI 的变化。

一个简单反例是 $g=(c+a)e_1$：属性 $c$ 和外观变化 $a$ 沿同一方向。类内 SVD 找到 $e_1$，硬投影会同时删除全部属性差异。因此，类内方向的来源与类间方向的重叠必须实测。

与文本阶段的相似处是使用投影；区别是已知输入在相应线性层处具有明确的线性代数关系，而这里的干扰方向来自有限候选的统计估计。第一阶段若使用替代图像，其特征也不等于真实视觉上下文，不能声称已精确消除真实图像影响。二者可以共享设计动机，不能共享未经证明的精确消除结论。

### 与 LDA 及白化的关系

硬投影、Fisher LDA 和 Whitened cosine 是不同对照。令 $S_W=EE^\top$，二分类的正则化 Fisher 方向形如

```math
w=(S_W+\lambda I)^{-1}(\mu_1-\mu_0).
```

它按类内协方差调整类间差异；硬投影直接删除选定方向；白化后余弦还会归一化向量长度。三者通常不等价。高维小样本协方差必须正则化。LDA 的公共协方差模型与 Mahalanobis 几何见 [官方数学说明](https://scikit-learn.org/stable/modules/lda_qda.html#mathematical-formulation-of-the-lda-and-qda-classifiers)。

二分类 Fisher 判别子空间最多一维，中心化后一维余弦会退化为符号。若测试 LDA，使用连续判别分数或正则化距离，不用一维余弦评估排序能力。

### 验证实验与判定

| Experiment | Design | Evidence |
|---|---|---|
| A1 评分机制消融 | 固定候选、文本和上传；分别测试原 Top-3、原型评分、硬投影、软抑制及正则化 Fisher | 分清收益来自聚合规则还是子空间变换 |
| A2 方向覆盖验证 | 用部分公开风格拟合，在未参与拟合的同类图像上测量投影后的变化 | 库外类内变化也下降才支持可迁移抑制 |
| A3 语义保留验证 | 记录投影前后类间距离、类内散度、目标残差范数及 Balanced accuracy | 不能只报告类内方差下降 |
| A4 领域留出 | 公开开发阶段逐域留出；冻结规则后测试完全未用于拟合和调参的领域 | 未见域仍有收益才支持降低域依赖 |

$k$ 和 $\alpha$ 的候选网格应很小，并在公开开发数据上选择。首轮先分张量做 SVD，或使用低秩 Gram 计算；不要显式构造巨大的 $p\times p$ 投影矩阵。全梯度拼接时，张量尺度处理需固定，并单独比较其影响。

若只在拟合库内变好、留出候选无收益，或类间信息随投影一起消失，应暂停“外观消除”解释。若软抑制在独立数据上优于硬投影，可以继续研究统计稳健性，而不要求完全分离语义与外观。

## 方案二 张量判别加权

建议工作名称为 **Tensor Discriminability Weighting**。当前权重的单位是参数张量，称为 Layer-wise 时需要明确如何汇总到层；LoRA-A、LoRA-B、模块与层位置应分别记录。

### 思路与数学形式

对每个实际上传的张量 $\tau$，计算候选梯度的类间散度与类内散度：

```math
B_\tau=\sum_c n_c\|\mu_{\tau,c}-\bar g_\tau\|_2^2,
\qquad
W_\tau=\sum_c\sum_{i:c_i=c}\|g_{\tau,i}-\mu_{\tau,c}\|_2^2.
```

原始比值 $B_\tau/(W_\tau+\epsilon)$ 可作诊断。实际加权建议测试有界版本，避免极小分母造成单个张量独占：

```math
r_\tau=\frac{B_\tau}{B_\tau+W_\tau+\epsilon_\tau},\qquad
w_\tau=\frac{1-\beta}{T}
+\beta\frac{r_\tau}{\sum_{\nu=1}^{T}r_\nu},\quad 0\leq\beta\leq1.
```

$T$ 为有效张量数，$\beta=0$ 是等权对照；所有 $r_\tau$ 都无有效信号时回退等权并记录状态。$\epsilon_\tau$ 采用公开候选能量对应的相对数值阈值，避免绝对常数改变缩放性质；具体规则在开发阶段冻结。

先沿用当前每候选评分和 Top-3 聚合，仅替换张量权重：

```math
d_i=\sum_\tau w_\tau\left[1-\cos\!\left(
g^\star_\tau-\bar g_\tau,
g_{\tau,i}-\bar g_\tau\right)\right].
```

权重由候选梯度及候选标签产生，目标梯度只进入最终匹配。每个目标采用对所有候选一致的有效张量规则，不能因候选类别不同而选择不同张量。

### 需要修正的解释

- **比值首先表示候选库内判别力。** 若头部候选都带黑背景、非头部都带白背景，高比值可能反映背景。必须平衡属性与风格，并检验留出域。
- **不能预设深层更可靠。** 这里观察的是语言模型 LoRA 参数梯度，不是直接比较视觉编码器浅层纹理与深层语义。梯度同时受答案损失、反向误差信号和参数化影响，层位置趋势应由实验发现。
- **张量数从 Observation 读取。** “448 个”不能当作跨模型常数；不同微调范围及 rank 会改变可用统计结构。
- **有缓存时无额外模型前后向，但不是零计算。** 需要统计量和评分计算。当前 PublicWorker 主要保存最终评分 JSON，没有持久化完整候选梯度；若没有其他缓存，需要重新回放候选。只有标量余弦分数不足以恢复上述散度。
- **张量之间可能冗余。** 多个高权重张量可以反映同一类文本关联，权重分布图不等于视觉语义的因果解释。

### 验证实验与判定

| Experiment | Design | Evidence |
|---|---|---|
| B1 单因素替换 | 对比 Global、Equal-tensor、Centered equal-tensor 与判别加权；固定候选数量及聚合规则 | 判断权重是否带来独立收益 |
| B2 外推能力 | 在公开候选的拟合部分算权重，用留出图像和留出风格测试 | 检验高比值是否预测库外判别效果 |
| B3 稳定性 | 多套独立候选库；报告权重集中度、排序稳定性及各域结果 | 避免少量候选或数值噪声决定权重 |
| B4 反证对照 | 打乱候选标签后重算权重；置换权重与张量对应关系；对比 Text-only 和 Wrong-gradient | 验证收益来自有意义的候选类别结构与目标更新 |

深度图同时展示模块、LoRA 因子、候选库与文本条件，不能先合并成“深层语义更强”。若它只改善医学库而无法改善域外候选条件，应表述为评分改进，不能宣称已经解决域依赖。

## 方案三甲 文本引导候选生成

建议工作名称为 **Text-Guided Candidate Generation**。它使用生成图像及生成模型先验，不能称为 Image-free 或 Zero-prior。

### 思路与适用范围

从 $\hat q,\hat a$ 提取场景线索，将同一场景描述与各个预定义属性值分别组合，生成数量相等的候选。生成器可以补充多样性，但不能把生成内容当作目标真实内容。

该方案适合“问答能够透露场景、但未直接回答待测属性”的条件。问答缺少领域线索时，自动场景判断仍可能错误；此时应使用预先定义的多域候选策略或明确场景未知，不能由评估端补入真实模态。

### 验证实验与判定

| Experiment | Design | Evidence |
|---|---|---|
| C1 场景信息分组 | 在独立开发数据上预先区分场景明确、模糊、缺失的问答；同一生成策略覆盖全部组 | 确定收益适用范围 |
| C2 场景扰动 | 固定属性与候选预算，对比无上下文、恢复上下文及人为错误上下文；真实领域仅作显式诊断 | 测量对场景判断错误的敏感度 |
| C3 梯度增益 | 同一生成库比较完整方法、Model-only、Text-only 和错配梯度 | 排除只根据问答猜属性的收益 |

生成标签需独立核验；相同场景条件应对各属性类别一致。若收益只出现于场景明确组，把它保留为条件性组件，不作为降低图像先验依赖的主方案。

## 方案三乙 视觉残差子空间概念探针

建议工作名称为 **Visual Subspace Concept Probing**。它可以先作为无需候选图像评分的探针，但“同维空间意味着语义几何对齐”需要独立验证。

### 首层梯度实际能推出什么

以 LLaVA 首个语言层中接受归一化输入的 LoRA 线性映射为例，设 $X$ 的每行是该映射真实接收的一个 token 特征。LoRA 更新为 $sBA$，则

```math
G_A=sB^\top\Delta^\top X
=C_tX_t+C_vX_v,
```

其中 $X_t$ 包含文本和模板位置，$X_v$ 包含视觉位置。若已知正确 $X_t$，并构造使 $X_tP_t=0$ 的投影，则

```math
G_AP_t=C_vX_vP_t,
\qquad
\operatorname{row}(G_AP_t)
\subseteq\operatorname{row}(X_vP_t).
```

**这是包含关系，不能改写为完整视觉子空间的相等关系。** 反向系数、LoRA rank 与任务损失会限制可观察方向；单个 LoRA-A 块秩不超过 rank。LLaVA 首层三个同输入的 Q/K/V 块在 rank 32 时，堆叠秩最多为 96，并不保证覆盖全部视觉 token 方向。

这与 DAGER 利用梯度约束输入特征的思路有关，但 DAGER 的离散文本候选来自实际输入词表；“图像含有头部”并不要求视觉 token 等于 `head` 的词嵌入。[DAGER](https://arxiv.org/html/2405.15586v2)

还需要处理三个问题：

- 实际输入是首层归一化后的特征，不能直接用未归一化词嵌入构造投影。更深层的文本激活已依赖图像，不能仅凭恢复文本准确生成。
- 使用错误的恢复文本时，未消掉的文本方向和误删的视觉方向都可能存在。若概念词已出现在问答中，它的投影可能接近零；零残差不是属性存在的证据。
- Projector 输出与词嵌入维度相同，不保证二者的欧氏距离或子空间距离可表达属性。CLIP 中也观察到模态间几何差异；这一研究仅提示需要实测，不能直接当作 LLaVA 的结论。[Mind the Gap](https://arxiv.org/abs/2203.02053)

### 可检验的探针

本节将 $S$ 存为 $G_AP_t$ 行空间的正交行基，$e_c$ 为预先确定、经过对应归一化的概念行向量，可以测试

```math
d(c)=\frac{\|e_cP_t(I-S^\top S)\|_2}
{\|e_cP_t\|_2}.
```

该分数是几何启发式，不是属性概率。分母过小时必须标记为不可判定。多 token 词、同义词和反例词簇的构造规则应预先冻结；不要把否定词前缀视为可靠的“非头部”向量。若引入公开图文训练的对齐层，应单独声明新增的辅助数据依赖。

### 验证实验与判定

| Experiment | Design | Evidence |
|---|---|---|
| D1 几何前提 | 先在独立公开标注图像上，直接测量实际视觉 token 子空间能否区分固定正负概念 | 直接表征条件也不分离，则先暂停原始词向量方案 |
| D2 梯度信息损失 | 同一公开样本比较直接视觉残差空间与梯度残差空间；先正确文本，后恢复文本 | 分清几何对齐、LoRA 压缩和文本误差 |
| D3 空间对照 | 等秩随机子空间、其他图像子空间、语义无关词簇及词簇置换 | 排除秩大导致任何词都容易靠近的假象 |
| D4 语义泄漏控制 | 记录概念出现在问答中和未出现时的表现；评估同义词稳定性与投影近零比例 | 防止把文本重复、词频或近零向量当视觉证据 |

D1 只用公开开发图像；如果另用目标真图做诊断，必须在评估端执行并标记私有参考使用，不能反馈攻击选词。D1 成功仍不是 D2 必然成功的保证，直接视觉空间也不被称为严格性能上界。

## 补充方案 视觉 tokens 恢复与属性读出

这是此前讨论的 **Visual Token Recovery** 路线：以进入语言模型的视觉 tokens $Z$ 为变量，固定恢复问答，通过梯度匹配求解

```math
\hat Z=\arg\min_Z D\!\left(\nabla_\theta\mathcal L_\theta(Z,\hat t),g^\star\right)
+\lambda R(Z).
```

固定 $\hat Z$ 后，用预先确定的属性问题读取结果，比较相反属性的答案分数。属性答案不加入同一优化目标，否则可能只是把期望答案写入自由 tokens。

### 可行性与限制

- 在冻结视觉编码器和连接层、只上传语言模型参数梯度的 F-L 条件下，替换接口有明确的计算意义。若连接层也训练，直接优化其输出会丢失上游梯度约束，需要另行设计。
- 它减少了目标域候选库依赖，但自由 tokens 可能偏离真实图像特征分布。范数约束只能提供部分限制；若采用公开图像训练的表征先验，必须说明其来源。
- 视觉 tokens 的变量数未必比像素少，优化也不保证更容易。必须同时记录时间、显存、迭代预算和多初始化稳定性。
- 相近梯度可能对应不同属性；如果多个匹配良好的解给出相反属性，说明当前约束和读出不能稳定确定该属性。

CapRecover 展示了从已获得的视觉特征解码标签与描述的研究方向，但其攻击者直接获得特征并训练解码模块，不能作为从 LoRA 梯度恢复语义的可行性证明。[CapRecover](https://arxiv.org/abs/2507.22828)

### 验证实验与判定

| Experiment | Design | Evidence |
|---|---|---|
| E1 接口与读出检查 | 在公开样本上验证注入真实 tokens 后 logits 与 LoRA 梯度一致；检查原模型属性识别能力 | 排除实现错误及读出器本身不具备能力 |
| E2 独立初始化恢复 | 随机或预先声明的公开初始化；固定问答和预算；仅按可观察匹配分数选择 | 判断低梯度误差是否对应正确语义 |
| E3 多解与控制 | 多初始化、分层留出梯度块检验、错配梯度及无目标梯度控制 | 识别过拟合梯度、模型先验及相反属性解 |

E1 是公开样本正确性诊断，不使用目标真图初始化。若最终需要目标私有特征比较，只能在重构保存后评价。先验证属性分类，不扩展到自由 caption 或生成图像。

## 共用评估协议

### 候选与数据划分

候选类别与领域尽量交叉平衡：每个领域都包含正负属性，并尽量匹配背景、主体占比和生成预算。先使用明确、可标注的属性；“非头部”应记录具体负例类别，防止负例构成变化冒充泛化提升。

采用三部分：公开拟合库、公开开发集、独立目标测试集。方案一和二在公开库拟合统计量，在开发集确定超参数，在目标测试集只执行冻结规则。开发阶段做领域留出，正式测试保留从未参与拟合或调参的领域。生成图按源图或内容家族分组，不能把同一图的不同风格变体分到拟合与验证两边。

当前二十张目标已被反复分析，可用于机制诊断，不作为新方法最终确认集。三套候选库是同一批目标上的重复测量，不能当作六十个独立目标。正式验证尽可能按患者分组；没有患者标识时报告这一限制。

### 对照与指标

| Item | Required comparison |
|---|---|
| Existing scores | Global、Centered、Equal-tensor、Centered equal-tensor |
| Aggregation | 固定 Top-3；原型评分另作消融 |
| Target gradient | 正确梯度与错配梯度 |
| Priors | Text-only、Model-only；无图像方案采用对应的无目标梯度控制 |
| Text | 恢复文本主结果；显式 text_known 诊断 |
| Domain knowledge | 目标域标签未知、目标域不在候选库、无需图像库分别报告 |
| Classification | Balanced accuracy、Macro F1、每类 Recall、AUROC |
| Uncertainty | 目标级配对区间、多库稳定性；若拒答则同时报告覆盖率 |
| Cost | 候选回放次数、评分耗时、内存、优化预算 |

属性在全部目标上按同一规则预测，禁止只报告容易猜中的属性或只报告正确的正例。阈值在开发集校准；重复尝试多个方法后，应冻结一个主方法再做独立测试。

错配梯度会同时改变图像和问答，不能单独证明视觉因果作用。另建小规模控制组：不同图像具有相同且有效的问答、相反的目标属性；保持模态和主要外观尽量一致，交换观测梯度，看预测是否随目标图像属性改变。该组只能评价受控情景，不能替代自然分布测试。

### 逐步执行顺序

1. **整理缓存与固定对照。** 检查已保存的是完整候选梯度还是最终分数；冻结图像、问答、模型和候选预算，记录候选拟合与开发划分。
2. **先跑方案二。** 检查权重的库外有效性，再看当前医学库与通用库上的增益。保留无权重基线。
3. **再跑方案一。** 先比较原型聚合与当前 Top-3，然后单独比较软抑制、硬投影和 Fisher；分别有效后才组合权重与投影。
4. **检查概念探针的几何前提。** D1 无效则暂停直接词向量探针，不把其失败等同于梯度没有语义信息。
5. **按前述结果决定表征恢复投入。** 通过 E1 后才进行小规模 E2；场景生成保留为文本信息充分时的补充实验。

首轮不同时扩展 batch、多步更新、噪声和多模型，避免把属性可辨识性与其他退化混在一起。待一种路线在独立目标及未见领域上稳定优于原评分和先验对照，再测试这些条件。

## 预期论文贡献与判断边界

Fisher 比值、类内协方差和正交投影本身是已有统计工具。研究贡献需要落在：图文耦合梯度中什么信息可用于属性判断，哪些候选变化妨碍迁移，以及方法是否在目标域未知或缺席时仍有可复现增益。

最值得优先验证的问题是：**公开候选中可重复的属性差异，能否从类内变化中分离，并迁移到未见领域的客户端梯度？**

如果答案只在已覆盖领域成立，应报告适用边界；若只有文本直接提示属性时成立，仍需通过 Text-only 对照确认梯度的增量；若候选无关的探针或视觉表征恢复成功，才有更强的证据支持减少图像库依赖。


## 本轮执行设计（2026-10-28）

以下集中保留本轮两个阶段的冻结设置；运行经过与结果统一放在实验记录，原 outputs 计划和源码快照保留，不改动冻结产物。

### 候选统计评分 {#scoring-design}

#### 研究范围

- 张量判别加权是否优于不加权评分，能否改善通用摄影候选对医学目标的迁移？
- 类内软抑制或硬投影是否优于相同的原型聚合？收益是否伴随类间信号损失？
- 改进是否超出 Model-only、Text-only 和错配梯度对照？

沿用此前二十图，只作机制诊断，不作为新方法独立确认集。无需重新训练、捕获上传、重构文本或生成图像。仅增加 `evaluation/` 评分代码及数学正确性测试。

#### 固定设置

| Item | Setting |
|---|---|
| Targets | 原二十图，Head 与 non-head 各十图 |
| Model | 原 LLaVA-1.5-7B，F-L，Rank 32，Round 10 |
| Upload | 原单样本、单步 FedSGD，无防御 |
| Text | 已保存的 Residual v1、LM prior 0.01 重构；独立 text_known 诊断 |
| Candidate banks | 三套通用摄影库及一套医学库，各二十四图，类别平衡 |
| Candidate budget | 每份不同问答回放九十六图；不同阶段同问答复用内积 |
| Baselines | Global、Centered、Equal-tensor、Centered equal-tensor，Top-3 |
| Weighting | 有界类间散度比例；beta 为 0、0.5、1 |
| Suppression | 每张量类内 SVD；k 为 1、4；alpha 为 0.5、1；等权原型余弦 |
| Fisher | 每张量正则化 Fisher 连续分数，类间距离归一化后等权；ridge 为 0.1、1 倍类内平均能量 |
| Negative controls | 候选标签打乱后拟合权重；权重与张量随机对应；其他十九份上传 |
| Hardware | 先在共享 GPU 5 保存首份缓存；用户随后指定空闲 GPU 6，剩余回放迁移至 GPU 6 |

#### 公开选择与预测边界

每套通用库用自己的二十四图拟合，在另外两套通用库上检验。以重构问答为上下文，对不同问答、拟合库和留出库等权汇总 Balanced accuracy。分别选加权、抑制和 Fisher 的一个配置；并列时按表中顺序优先选择更简单的配置。目标梯度、目标标签和医学库不参与选择。

留出库使用不同种子，但提示家族和摄影领域相同，不能称为未见领域验证。医学目标的迁移仅属诊断；其标签在全部配置预测和选择规则保存后才由评估端读取。正确文本不参与配置选择。

拟合和留出图像不重叠；每张量使用相同候选集合。中心仅由拟合候选均值得到。采用 float64 内积和低秩 Gram 分解，不构建参数维度的稠密投影矩阵。退化向量按无有效证据计入覆盖率。

#### 判定与报告

主比较为三套通用库平均的重构文本 Balanced accuracy：所选加权对比 Centered equal-tensor。抑制对比 Prototype equal，并另列原 Top-3，分离聚合变化与投影收益。所有候选配置均报告，避免只展示最优目标结果。

报告 Accuracy、Balanced accuracy、Macro F1、Head recall、AUROC、有效覆盖率，及目标级分层配对 bootstrap 区间。三套库是相同二十目标的重复测量，不作六十个独立目标。附公开留出准确率、权重集中度、投影后类内变化与类间距离保留、错配梯度、既有先验基线及实际成本。

若只有拟合库内变好，或目标收益区间含零，先报告边界；不自动扩大到视觉 tokens 优化。若出现稳定增益，再冻结主方法，申请新的独立目标确认；当前二十目标不能用于最终定论。

#### 冻结设计

| Item | Setting |
|---|---|
| Model | 原 LLaVA-1.5-7B，F-L，Rank 32，Round 10 |
| Public images | 已保存的三套通用摄影候选及医学合成库，共九十六图，Head 与 non-head 各四十八图 |
| Private data | 不读目标 Observation、真图、重构问答或目标标签 |
| Primary words | head、brain、skull、face 对 chest、abdomen、arm、leg |
| Synonyms | head、cranium、forehead、scalp 对 torso、belly、hand、foot |
| Unrelated words | table、chair、door、window 对 river、mountain、tree、cloud |
| Text context | 主条件为固定的 Describe the image. 与 The image is shown.；另测包含 head 的固定文本 |
| Feature | 视觉连接层输出经第一语言层 input RMSNorm；词嵌入经过同一 RMSNorm，多 token 词取片段均值 |
| Primary space | 减去固定文本方向后的视觉行空间，截断到前九十六方向 |
| Other ranks | 三十二、完整视觉数值秩，最多五百七十六；不按标签选择 |
| Controls | 原始空间、等秩随机商空间、预定同库其他图像空间、无关词簇、词簇置换、同义词及文本重叠 |
| Scores | 每词相对残差范数，类别内有效词求均值；每类至少两个有效词，否则拒答 |
| Numerical policy | float64 分解及距离；rtol=1e-6，atol=1e-10；近零文本残差不给正证据 |
| Readout | 固定问句 Does this image show a human head? Answer yes or no.；比较 yes 与 no 的原生答案 NLL，包含 EOS |
| Interface check | 四个预定公开样本检查真实视觉 tokens 注入后的 logits、loss 与全部 LoRA 梯度，容差 1e-6 |
| Hardware | WN-A100 GPU 1，当前显存占用最少且无任务；已有 gia 环境 |

词簇、分词策略、随机种子、其他图像映射和秩均在执行前固定。公开图像标签仅由评分完成后的评估端用于统计，不据此改概念或选择秩。随机空间相同秩与上下文复用同一随机基，保持与图像属性无关。

#### 指标与推进条件

逐库报告 Balanced accuracy、Head recall、AUROC、覆盖率及每个概念词的分离情况。三套摄影库来自同一提示家族，不能当作独立领域；报告合并摄影组和医学组。区间按公开图像重采样，并另按部位提示家族聚类检查，避免将相似种子的差异当作语义泛化。

本轮没有任何参数拟合或阈值校准。进入 D2 的保守条件是：主探针在合并摄影组与医学组均达到 Balanced accuracy 0.65，AUROC 的图像级 95% 区间下限均高于 0.5，且三套摄影库的分数方向一致。完整网格和失败条件也报告；不因为别的秩或词簇恰好更好就替换主条件。

接口一致性通过只说明可以把视觉 tokens 作为可替换输入，不说明梯度能恢复其语义。读出检查对比真实视觉 tokens 与全零视觉槽位；全零槽位是消融，不是标准 Text-only，也不是合法图像分布。若原模型属性读出不可靠，应先解决读出，再考虑自由 tokens 优化。
