# Raw：直接用梯度空间筛选

| Item | Setting |
|---|---|
| Implementation | `dager_adapted` |
| Mode | `attack.dager.mode=raw` |
| Role | 当前 Residual 方案的打分对照 |
| Candidate feature | 第一层输入 RMSNorm 后的 token embedding |

## 梯度为什么包含输入线索

对一个线性层，一行权重梯度是各个输入向量的加权和。LoRA-A 梯度是对权重梯度的线性压缩，因此每行仍保留这种关系。以一行梯度作示意：

```text
g = a × p + b × x₁ + c × x₂
```

`g` 是观测到的梯度行；`p` 是一个已知输入向量；`x₁`、`x₂` 是实际使用的私有文本向量。系数来自反向传播，攻击者不知道它们。

把梯度的各行任意加权组合，能得到的所有向量组成了**梯度行空间**。Raw 枚举词表中的每个候选，计算其输入特征到这个空间的相对距离，按距离从小到大排列。

!!! note "这个推理只有一个方向"
    梯度行空间包含于实际输入张成的空间。由于 LoRA 压缩和反传系数的影响，反过来不能保证每个真实 token 都在观测梯度行空间中；接近这个空间也不能证明 token 出现过。

## Raw 实际怎么打分

1. 从上传梯度中取第 0 层 Q、K、V 对应的 LoRA-A 梯度。
2. 按各自的 Frobenius 范数归一化，堆叠三组梯度，提取正交行基 `S`。
3. 对每个候选 token 计算特征 `x`，得到到 `S` 的相对距离。

```text
distance(x, S) = ‖x − (x Sᵀ) S‖₂ / ‖x‖₂
```

`S` 的每行是一个相互正交的单位方向。`(x Sᵀ) S` 是 `x` 在这个空间中的投影；分子是空间外的剩余长度，分母消除向量长度的影响。

## 干扰来自哪里

梯度同时混合了图像、模板和私有文本的信息。某个没有出现的候选也可能与图像或模板的方向相似，从而得到比真实 token 更小的距离。

[Residual v1 的例子](residual-v1.md#worked-example) 展示了这种误排，以及同一投影如何改变排序。

## Raw 与图像条件

在同一个模型和观测梯度下，Raw 的**第一阶段词表分数**不依赖选用真实图像还是随机替代图，因为它不构造图像投影空间。

第二阶段仍要把图像与候选前缀一起输入模型，所以 **Raw 的序列结果仍可能随图像改变**。不能把第一阶段不依赖图像，推广为整个方法不依赖图像。

对应代码：`SpanFilter.build()` 中 `mode == "raw"` 的分支，以及 `SpanFilter.score()`。结果见 [[dager-multisample-n10]] 和 [[dager-lora-rank]]。
