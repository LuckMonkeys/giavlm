# 候选改进与验证状态

这些研究尝试改变第一阶段的证据或排序方式。它们没有替代当前 [Residual v1](residual-v1.md)，也没有注册为新的默认攻击。

## 第一阶段改进

| Candidate | Motivation | Mechanism | Current decision |
|---|---|---|---|
| 稀疏字典排序 | 单独看距离可能混入不能共同解释梯度的 token | 将高排名候选作为字典，联合拟合梯度，按候选系数排序 | 已知图像下有效；随机图像验证退化，保留为研究变体 |
| 公开视觉统计加权 | 随机替代图的视觉方向不准确 | 用公开图像统计视觉方向及强度，软抑制后做联合拟合 | 开发集收益未通过独立验证 |
| 逐 token 校准 | 不同 token 的低距离可能来自不同背景分布 | 用公开反事实样本估计非成员距离分布，再与原排名融合 | 随机复现无稳定收益，未采用 |
| 多随机图融合 | 单个替代图可能带来偶然排序误差 | 分别用多个随机替代图打分，再融合排名 | 已测三种子的固定预算覆盖未改善 |
| 谱处理与 QKV 排名融合 | 弱奇异方向或某组投影可能带来噪声 | 截断、软加权或跨 Q/K/V 融合排名 | 未形成稳定替代方案 |

### 稀疏字典为什么可能改变排序

Residual 单独检查每个 token 与梯度空间的接近程度。稀疏字典进一步问：能否由一小组候选共同解释观测梯度？当前研究使用基线 Top-2000 informative 候选，通过带符号的 group lasso 拟合，再按候选系数排序。

这一步依赖字典覆盖、投影空间和求解精度。图像方向失配时，联合拟合可能选择一组更能解释失配残差的 token；因此“更好地拟合目标”不自动等于“更完整地覆盖真实 token”。这是对结果的机制解释，尚非因果分解结论。

### 公开视觉统计与多随机图融合有什么区别

多随机图融合先独立得到多个排序，再合并排名。公开视觉统计方法先改变向量空间中的方向权重，再进行候选联合拟合。两者修改的位置不同，不能合并成同一种“图像融合方法”。

所有开发、冻结参数和验证结果见 [[dager-filter-phase]]。该实验只验证 token filter，不据此宣称句子恢复改善。

## token–图像排序 {#image-ordering}

这个方向检验：代入正确 token 后，梯度损失能否更好地保持“图像离真值越近，损失越低”的排序。

现有测试用真实图像构造带远近关系的候选，并用真实文本确定探测位置和对照。因此它是**机制诊断**，尚未解决攻击者在图像私有时如何获得这样的候选集。

- 全梯度排序没有得到可作为通用 token 成员判据的证据。
- LoRA-A 的答案排序出现值得关注的次要信号，但属于同一小样本上的事后关注分组。
- 若继续，应先冻结规则，在新的多 token 答案上与平均梯度损失作配对验证。

完整条件和结果见 [[token-image-ordering]]。

## 哪些变化不构成 Residual 新版本

提高 LoRA rank 改变了模型和观测梯度的信息量。扩大 K 或 beam 改变了候选及搜索预算。这些变化值得实验，但只要投影、评分与解码规则没变，就仍是同一 Residual 方案下的条件对比。

rank 对比见 [[dager-lora-rank]]。当前判断仍以 [Residual v1](residual-v1.md) 为基准。
